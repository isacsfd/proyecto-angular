Página 3
Documento de documentación académica del proyecto “Biblioteca IUB”. Refleja el estado actual
del repositorio: Angular consume exclusivamente la API FastAPI; los módulos de Proveedores,
Compras y Detalles fueron migrados a FastAPI sobre MySQL; se retiró la API auxiliar previa
(Node/MySQL) del proyecto, por lo que ya no existe dependencia de ejecución hacia ella.
Descripción general
El sistema gestiona acceso y préstamos de recursos bibliográficos e informáticos de la
Institución Universitaria de Barranquilla (IUB): autenticación por roles (JWT + RBAC),
administración de libros, dispositivos y préstamos, catálogo con búsqueda tradicional y
semántica, recomendaciones, panel estadístico, registro de accesos por QR, módulo de
proveedores/compras y modo demostración independiente.
Arquitectura del sistema
Angular (SPA) consume una única API REST (FastAPI) con token JWT en el encabezado
Authorization. La persistencia principal está en PostgreSQL (Neon); el módulo de
Proveedores/Compras/Detalles usa una conexión independiente a MySQL (XAMPP) mediante
pymysql, sin afectar la base principal. FastAPI aplica autenticación, autorización por módulo
(RBAC) y reglas de negocio; los servicios de IA corren en el backend. El modo demostración es
exclusivo del frontend e intercepta las peticiones sin contactar la API. Se retiró la API auxiliar
previa (Node/MySQL); Angular ya no tiene dependencia de ejecución hacia ella.

Autenticación, autorización y roles
El login valida identificación y contraseña con bcrypt y emite un JWT (HS256, 8 h) con el rol
obtenido de la base de datos; el rol se revalida desde la base en cada petición protegida. En
producción MM_JWT_SECRET es obligatoria (garantiza claves no predecibles). Roles:
super_administrador, Administrador, Funcionario, Docente y Estudiante. Proveedores, Compras
y Detalles quedan restringidos a super_administrador y Administrador (403 para los demás). El
login además exige que el rol seleccionado coincida con el rol real de la cuenta.

Interfaz de usuario
Todas las pantallas (admin y usuario) usan SweetAlert2 (servicio AlertaService) para éxito,
validaciones, errores de conexión y confirmaciones, y formularios modales flotantes para el
registro/edición y gestión. Las tablas de Libros, Préstamos de libros, Catálogo y Mis préstamos
usan ngx-datatable con barra de paginación en la parte superior izquierda, búsqueda a la
derecha, ordenamiento y selección de tamaño de página. La paginación es local y calcula las
páginas a partir del total real filtrado (sin páginas vacías ni registros repetidos). La gestión de
préstamos de dispositivos (admin) conserva DataTables; la solicitud de dispositivos del usuario
es un modal.
